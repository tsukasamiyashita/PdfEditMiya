PdfEditMiya - 高性能PDFデータ抽出・編集ツール (v3.0.0)

PdfEditMiyaは、PDFファイルから表データやテキストを抽出し、ExcelやCSVなど、使いやすい形式に変換するためのWindows専用ツールです。最新のAIモデル（Gemini API および Azure OpenAI Service）やOCR技術を搭載しており、手書きの書類や複雑なレイアウトのPDFでも高精度に読み取ることができます。

主な機能

1. 自由自在なデータ抽出

表として抽出: PDF内の罫線や空白を認識し、エクセルのセルごとに綺麗に分割して出力します。

テキストのみ抽出: 指定した行（水平線）や列（垂直線・縦書き用）のテキストをピンポイントで抜き出します。

複数範囲の同時指定: 1ページ内の複数箇所を一度に選択し、それらを横並びに結合して出力することも可能です。範囲設定の保存・読み込み（プリセット機能）にも対応しています。

2. 用途で選べる4つの抽出エンジン

標準ライブラリ: パソコン上で作成されたデジタルPDF（文字選択ができるPDF）から、オフラインで高速・正確にデータを抽出します。

Gemini API (AI): Googleの最新AIを活用。手書き文字、かすれた文字、複雑な表構造も人間のように理解して読み取ります（無料枠・課金枠の切り替えに対応）。

Azure OpenAI API (AI・法人向け): Microsoft Azure上のセキュアなAIモデル（GPT-5 / GPT-6等）を活用。入力データが外部のAI学習に利用されない環境で、手書き文字や複雑な表を高精度に読み取ります。

Tesseract (ローカルOCR): インターネット環境がない場所でも、お使いのパソコン内でスキャンPDFの文字認識処理を行えます。

3. 多彩な出力フォーマット

データ系: Excel (.xlsx), CSV (.csv), JSON (.json), Markdown (.md), Word (.docx)

画像・図面系: JPEG (.jpg), PNG (.png), SVG (.svg), TIFF (.tiff), BMP (.bmp), DXF (.dxf / CAD用変換)

テキスト系: プレーンテキスト (.txt)

4. 便利なPDF編集・データ管理ツール

結合・分割・回転: 複数のPDFをファイル名の番号順に1つにまとめたり、ページごとにバラバラにしたり、ページの向きを直したりできます。

データ集約: 複数ファイルの表データを、列名を自動で判別して1つの大きなリストにまとめます。「〃」や「同上」などの省略記号も自動で上のセルの内容を補完します。

データ単純結合: 内容を加工せず、シンプルに複数のファイルを縦に繋ぎ合わせることも可能です。

PDFデータ構造を確認: 読み込んだPDFが「文字データ」か「画像（スキャン）」かを自動判定し、最適な抽出エンジンをアドバイスします。

動作環境

OS: Windows 10 / 11 (64bit)

その他: AIエンジン（Gemini API または Azure OpenAI API）を使用する場合はインターネット接続が必要です。

インストール・実行方法

特別なインストール作業は不要です。以下の手順ですぐにお使いいただけます。

1. ダウンロードした PdfEditMiya-v3.0.0.zip を右クリックして「すべて展開」をクリックします。

2. 展開されたフォルダ内にある PdfEditMiya-v3.0.0.exe をダブルクリックして起動します。

起動時にWindowsの警告画面が表示される場合（重要）

本ソフトを初めて起動する際、Windows Defender (SmartScreen) によって「WindowsによってPCが保護されました」という青い画面が表示されることがあります。これは開発元の電子署名登録を行っていない個人・社内向けソフト全般で表示される確認画面ですので、以下の手順で安心して実行してください。

1. 青い警告画面の左上にある「詳細情報」という文字をクリックします。

2. 画面の右下に新しく表示される「実行」ボタンをクリックすると、アプリが正常に起動します（2回目以降はこの画面は表示されません）。

基本的な使い方

1. ファイルを読み込む
アプリ画面上部の「ファイルを選択」または「フォルダを選択」ボタンを押して、処理したいPDFファイルを選びます。

2. 保存先を決める
「元のファイルと同じフォルダ」または「任意のフォルダを指定」から、変換後のファイルを保存する場所を選びます。

3. 抽出の設定を選ぶ
・① エンジン: PDFの種類に合わせてエンジンを選びます（迷ったときは「選択中のPDFデータ構造を確認」ボタンを押すと最適なエンジンが分かります）。AIを使う場合は「詳細設定」ボタンからAPIキーなどを設定できます。
・② 出力形式: Excel (.xlsx) や CSV (.csv) など、変換したい形式を選びます。
・③ 抽出モード: 表全体を取り出したいときは「表として抽出」、特定の行や文字だけを取り出したいときは「テキストのみ抽出」を選びます。

4. 範囲を決める（必要な場合のみ）
ページの一部だけを読み取りたい場合は、「抽出範囲を選択」ボタンを押してマウスで読み取りたい場所を囲みます。ページ全体を読み取る場合はそのままで構いません。

5. 実行する
画面右下の「選択した抽出・変換を実行」ボタンを押すと処理が始まり、完了すると指定したフォルダにファイルが保存されます。

困ったときは

アプリ画面右上の「❓ ヘルプ / 使い方ガイド」ボタン、または左上の「ヘルプ」メニューから、図解カードや比較表付きの「使い方ガイド」「PDFの内部データ構造について」「AI・OCRの準備」「よくある質問 (FAQ)」「バージョン履歴」をいつでも確認いただけます。
